Yahoo Finance Stock Analysis

An incremental-load pipeline and ML models for spotting overbought/oversold stock conditions

What I Did

Built a pipeline that pulls historical stock data via the Yahoo Finance API (yfinance) and processes 500K+ records to analyze market momentum. I calculated RSI and moving-average indicators to flag overbought/oversold conditions, then applied SVM and logistic regression models with statistical hypothesis testing to predict short-term trend direction. Data was loaded into PostgreSQL using an incremental, log-based load pattern rather than a full reload on every run.

Why I Did It

I wanted to combine two things I was curious about — financial markets and applying classic ML models to real, noisy time-series data — while practicing the incremental/log-based loading pattern that's central to production data pipelines, instead of the simpler full-batch-overwrite approach most tutorials default to.
